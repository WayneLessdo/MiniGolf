# FoldPutt · 好玩研究所

12 个方向的独立可玩浏览器原型，用于体验后选择新功能。不是正式 iOS 功能，也不包含联网社区或在线匹配。

## 打开

直接双击 **FoldPutt-好玩研究所.html**，用现代 Chrome / Safari 打开；所有画面、代码和字体均无需联网。

或在项目根目录执行 `python3 -m http.server 4197 --bind 127.0.0.1`，访问 `http://127.0.0.1:4197/prototype/play-club/`。

两个地址的浏览器存储相互独立。存储被浏览器禁用时有提示，仍可继续试玩并导出候选。

## 先这样玩

1. 进入“借一面墙的力”，按住球或圆形拉杆，向目标反方向拖，松手击球；滚动时拉杆锁定。
2. 进入“一洞一朵小花”，完成一洞后去花园选择花种和空格，再试移栽。
3. 进入“造一张朋友会骂的图”，点工具和网格，撤销/重做，校验后用同一手势试玩，再保存。
4. 对喜欢的玩法点“加入候选”；在“我的候选”打分、写理由、导出 Markdown 文件。

每个方向右侧有设置、收藏与“查看取舍”。后者解释目标用户、复玩理由、成本、风险和观察指标。

## 源文件

- `data.js`：12 个方向、主题、地图、原创 SVG 插画。
- `engine.js`：原型固定步长物理、单指拖杆、键盘等价输入、Canvas 表现。
- `app.js`：玩法循环、收藏、结算、编辑器、本地记录和导出。
- `style.css`：响应式布局、焦点状态、减少动态效果。
- `build.py`：更新单文件成果；执行 `python3 prototype/play-club/build.py`。

实际运行截图与验证范围见 `docs/play-club-delivery.md`；测试脚本与记录位于 `work/play-club/`。
