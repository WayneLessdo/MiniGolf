# FoldPutt · 小草坪俱乐部

独立的手绘互动概念，展示 Q 版球体、球杆挥击、手写拟声词、擦洞对视与入洞小剧场。全部画面由本地 SVG/CSS 绘制，无第三方依赖、远程字体或网络素材；不接入 Swift 工程及正式物理。

直接打开 `index.html` 即可离线使用，也可在项目根目录运行：

```sh
python3 -m http.server 4186 --bind 127.0.0.1
```

访问 `http://127.0.0.1:4186/prototype/cozy-putt/`。

- 鼠标/单指按住小球，向击球的反方向拖动，同时确定方向与力度，松手击球。此处轨迹是效果演示，不是正式关卡物理。
- 右侧五个入口和下方三张故事卡可以点播；“帮我打一杆”也支持键盘触发。
- 顶部切换软乎乎/有点皮：同步切换气氛、表情与文案。
- 桌面球友卡可切换糯米、桃桃、芝麻外观；声音独立开关，默认关闭。
- 响应系统 Reduce Motion 及运行中变化，也提供减少动效按钮；弱化模式直接呈现静态状态，无滚动/摇晃/粒子运动。
- 重开、Escape、切换气氛及后台中断会取消旧动效，避免上一段演出写入新一杆。

这是浏览器概念稿。视口与截图不代表 UIKit size classes、原生 safe area、DUO reserved regions 或 Device Hub 验证。
