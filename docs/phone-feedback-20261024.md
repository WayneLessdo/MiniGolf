# iPhone 17 Pro 反馈修订 · 最终构建 11

用户反馈：iPhone17Pro／iOS26.5.2，构建7声音和玩法正常，但挥杆未感到震动；要求轻触感、普通模式球杆、首页隐私/语言图标移到顶部，并进一步明确与品牌同排、缩小一半、靠拢且右对齐模式卡片。本记录不把“声音和玩法正常”扩大为完整真机验收。

## 最终实现

- 品牌文字在左、隐私/语言在右，属于同一固定顶栏，垂直居中，随滚动保持可见。大字号品牌可在自身区域换行，不覆盖图标。
- 可见底板24pt、符号11pt（原48pt/22pt的一半），保留44×44pt透明点击热区；两热区之间无额外间隙，可见底板之间20pt。语言底板的可见右边缘与模式卡片右边缘重合，透明热区向右多出10pt，仍在安全区内。有本地化VoiceOver名称、大内容查看标题、主题描边及轻阴影。
- 触感器由当前scene保留并关联root view；拉杆开始时预热，接受一次有效发球后触发一次`.light / 0.6`。取消、无效松手、重复release不触发，触感关闭时不预热/播放，scene断开释放。声音/触感仍独立，保留原选择；Reduce Motion仅抑制视觉动态，不再吞掉已开启的轻触感。
- 普通模式复用Q版球杆的投影和0.24秒随挥，换成草地主题配色；随方向和力度后撤、松手随挥。仅作用于视觉，物理/分数不变。减少动态时保留静态拉杆提示，关闭随挥；Q版与反弹课题玩法保留。

旧实现的临时soft反馈、0.22强度、未预热和Reduce Motion条件是可改进因素；没有真机日志，不能认定是此前未震动的唯一原因。真实Taptic Engine感受仍需用户在构建11复验。
