# DUO Lab 本地交互原型

日期：2026-09-30

## 交付范围

新增 `/prototype` 独立网页，用于在技术栈确认前评审五个 DUO 玩法方向。网页只表达玩法信息架构、交互节奏与视觉氛围，不替代 Swift + UIKit 实现，也不把概念交互标成真实 DUO 运行截图。

## 玩法表达

| 方向 | 网页可操作演示 | 规划判断 |
| --- | --- | --- |
| A 双屏物理解谜 | 风场节点拖动、拉力环、PUTT | 教学与规则关系最清晰，建议作为首个教学洞候选 |
| B 半折掌机弹珠 | 折痕视觉、拉力环反弹反馈 | 掌机感最强，需控制按钮避开 division |
| C 中缝运河视差 | 中缝运河、桥梁展开 | 最能形成 FoldPutt 记忆点，依赖关卡设计 |
| D 外屏快推 / 内屏策略 | 快推 → 路线编辑 → SHOT 连续性 | 最适合产品化，但策略面板要保持克制 |
| E 镜像时空 | 现实/镜像双栏、同步球路 | 惊喜感高，教学成本也最高 |

## 视觉资源

`prototype/assets/fp-duo-orbit.svg` 与 `prototype/assets/fp-duo-glyphs.svg` 为本地生成的 SVG 资源，采用草地、运河、琥珀球与薄荷高光，服务于概念预览。没有把现有 Xcode 资产改写或覆盖。

## 适配与边界

- 网页在 375px、768px、1024px、1440px 级别通过 CSS 响应式收敛；小屏会将概念 rail 折为横向选择带。
- 网页使用 CSS/DOM 模拟设备舞台，未读取真实 DUO reserved regions、safe area 或 size class；这些仍属于后续 Swift/UIKit 运行验证。
- 交互全部保留单指拖拽拉杆的语义，没有加入旋球、第二个确认按钮、付费、广告或姿态锁定。
- 真实图片生成工具在当前环境不可用，因此采用可审查、可版本化的本地 SVG 程序化资产；若后续需要 raster 视觉，再单独生成，不覆盖本轮资产。
