# FoldPutt 可扩展功能方向 · 2026-10-10

本页是正式 App 的建议池；12 个方向现已提供独立[可玩浏览器体验馆](play-club-delivery.md)，尚未接入正式 App。下列方向继续采用单指拉杆、无广告无付费、无体力与等待门槛；普通/Q 两种模式及单屏均可玩。借鉴玩法原则，不复刻角色、画面或数值养成。

## 市场依据

2026-10-10 读取官方产品介绍 / App Store 开发者描述，原始提取保存在 `work/map-replay-20261010/market-sources.json`。以下只使用开发者介绍中的事实，不把评论区建议当成现成功能：

- [WHAT THE GOLF?](https://apps.apple.com/us/app/what-the-golf/id1415190483)：荒诞物理高尔夫，不同关卡把猫、沙发、房子等变成意外主角，包含主题篇章。
- [Golf Peaks](https://apps.apple.com/us/app/golf-peaks/id1419542293)：轻松解谜、120 多个手工关卡、地形与障碍组合、无文字教程。它的卡牌输入不引入 FoldPutt。
- [Golf On Mars](https://apps.apple.com/us/app/golf-on-mars/id1509500916)：连续探索大规模火星球场。借鉴持续旅程，不引入评论提到的道具购买方案。
- [Golf Blitz](https://apps.apple.com/us/app/golf-blitz/id1413826211)：四人实时竞速、好友自定义比赛、观战与挑战规则。借鉴竞争与变化；其能力升级、内购体系不引入 FoldPutt。
- [8 Ball Pool](https://www.miniclip.com/games/8-ball-pool)：与好友打球、练习技巧的产品定位。
- [Dunk Shot](https://apps.apple.com/us/app/dunk-shot/id1301375510)：大众篮球投篮、持续挑战、解锁不同球外观。借鉴轻操作和目标接力，外观在本项目中免费。

## 推荐顺序

先做 **嘴硬球友＋下班打卡洞**：复用已有 Q 版和本次回放，内容成本低、辨识度高。
接着做 **反弹解谜＋睡前九洞**：直接增加能反复玩的地图内容，分别服务挑战和放松。
第三步做 **个人幽灵＋同机友谊赛**：提高复玩动力；在线多人和社区编辑器留到内容与规则稳定后再评审。

成本为相对判断（低/中/高），不是排期承诺。睡前模式对计时惩罚的豁免、新挑战目标和花园奖励均属于待确认产品建议，不改本轮正式奖惩规则。
