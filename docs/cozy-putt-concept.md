# 小草坪俱乐部 · 治愈 / 沙雕互动概念

## 本轮范围与来源

用户选择先看五个构思的丰富、可点击效果图：Q 版球体、球杆挥击、手写拟声词、擦洞对视、入洞吐槽。本次交付独立 HTML/SVG/CSS/JavaScript 视觉原型，路径为 `prototype/cozy-putt/`。它是交互评审稿，不是 UIKit 运行画面，也不是正式关卡物理。

原有单指拉杆决定方向和力度、松手击球的约束来自项目 AGENTS.md。奶油纸张、云朵练习场、糯米/桃桃/芝麻球、两套台词、场景观众与演出时间均为本轮设计建议。草地和角色为本地矢量绘制，未使用 AI 位图、远程字体或第三方引擎。手写短句使用系统楷体/宋体回退，正文使用系统可读字体。

UI/UX Pro Max 检索中的 Sketch Hand-Drawn 风格与本任务匹配，采用其纸张、轻微不规则边框、胶带与手写点缀建议。通用设计系统中的营销落地页结构、粉紫配色未采用。

## 可体验内容

| 构思 | 实际可操作效果 |
| --- | --- |
| Q 版小球 | 蓄力时认真/鼓腮；滚动时眯眼；擦洞时侧目；入洞开心。首个点播入口连续展示四种表情。可切换糯米、桃桃、芝麻外观。 |
| 球杆挥击 | 拉杆同时显示球杆后摆与轨迹提示；松手挥击，滚动过程中收起球杆；点击“帮我打一杆”也能观察完整演出。 |
| 手写拟声词 | 击球“啵”、经过沙地“沙沙”、入洞“咕噜”；有点皮模式击球用“走你！”。文字与轨迹出现在同一场景。 |
| 擦洞对视 | 小球从洞旁路过，洞口出现两只眼睛和问号。治愈版说“刚刚在叫我吗？”，沙雕版互相吐槽“你礼貌吗 / 路过，路过”。 |
| 入洞小剧场 | 粒子 0.8 秒；治愈版“到家啦”，沙雕版“终于下班了”。纸张纪念卡显示，再来一杆可重开。三颗星是概念纪念装饰，不代表正式标准杆星级规则。 |

顶部“软乎乎 / 有点皮”同步改变背景气氛、旗帜、表情与台词。右侧五个点播入口、下方三张故事卡、实际拖拽可配合体验。声音默认关闭；启用后使用本地 Web Audio 合成短音，不下载音频。

## 交互与动效边界

- 只有按住小球附近再拖拽、松手，才触发常规击球；无额外 PUTT 按钮、力度滑块或设备角度输入。
- 球路是概念演出：手动拖拽决定演示目标，靠近洞口触发入洞或擦洞反馈；自动点播使用编排轨迹。不能作为正式碰撞/沙地摩擦/分数验收依据。
- 所有 JS 时序集中在 `motion` 对象：挥杆 240ms、演示蓄力 780ms、普通滚球 1500ms、慢入洞 2050ms、沉球 270ms、入洞粒子 800ms、表情 850ms、一般气泡 1600ms。除既定入洞粒子外，其他均是待评审建议。
- 系统 Reduce Motion 初始值和运行中变化均生效；也可以手动切换静态反馈。静态模式直接展示状态，无滚动、旋转和粒子位移。
- 重开、Escape、切换氛围、后台中断会取消旧演出；更换点播项仅保留最新演出。拖拽取消与容器尺寸变化会取消未发出的杆。
- 使用语义按钮、键盘焦点提示和 live region；“帮我打一杆”和场景点播提供键盘等价预览。这不代表正式游戏的辅助技术瞄准方案已设计或验收。
