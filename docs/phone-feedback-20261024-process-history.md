# iPhone 17 Pro 反馈修订 · 最终构建 10

用户实测：iPhone 17 Pro，iOS 26.5.2，构建 7 的声音和玩法正常，挥杆没有感到震动；要求轻震动、普通模式球杆动效、首页隐私/语言移到右上角图标。该反馈只确认声音/玩法，不代替七语、积分、恢复或 Duo 真机完整验收。

## 修改

- 触感器从一次性临时 `.soft / 0.22` 改为当前 scene 持有、与该窗口 root view 关联的 `.light / 0.6`，拉杆首次进入准备阶段调用 `prepare()`，有效发球事件触发一次。取消/无效松手/重复 release 不触发，关闭触感开关时不预热或播放；声音仍独立控制。scene 断开释放反馈器，不使用全局屏幕或设备型号判断。
- Reduce Motion 控制球杆随挥、镜头与粒子等视觉动态；用户明确开启的轻触感由独立开关控制，不再被视觉减少动态设置吞掉。旧代码的弱强度、未预热和减少动态条件是可改进因素；没有真机日志，不能据此证明此前未震动的唯一原因。
- 普通模式在球旁显示球杆，跟随拉杆方向和力度后撤；松手后使用已有 Q 版 0.24 秒随挥曲线，颜色使用草地主题的深绿、浅色杆头与金色握把。只投影视觉，保持物理/分数不变；减少动态时保留静态拉杆提示，关闭随挥，Q 版原有表现不变。
- 首页隐私（手掌）/语言（地球）改为固定在与左侧“小草坪俱乐部”品牌文字同一条固定顶栏、垂直居中的图标，48×48pt 热区、12pt 间距、20pt 栏内左右余量、主题绿色描边与底部轻阴影。入口独立于滚动内容，不随下滑消失；有本地化 VoiceOver 名称与大内容查看标题。布局仍按容器、traits、四边安全区与系统保留区计算。

Apple 技术依据：[UIImpactFeedbackGenerator](https://developer.apple.com/documentation/uikit/uiimpactfeedbackgenerator)；本机正式 iOS27.1 SDK 头文件确认 `init(style:view:)` 自 iOS17.5 可用，项目最低 iOS18.0，无需新增依赖。

## 验证记录

69 项全量单元测试通过，包括新增“准备一次、取消不震、有效发球只震一次、独立开关、入洞反馈”测试。模拟器验证的是 API 调用及事件路径，不是 Taptic Engine 的实际感受。

真实 XCTest 拖拽采集普通模式拉杆画面，无注入球位/分数；`classic-actual-pull.png/json` 的 phase 为 charging、0 杆，随后真实 release 登记为 1 杆。画面来自 iOS18.5 大屏模拟器，正式 Xcode27.1 SDK；布局的 traits、安全区、reserved regions 与控件范围保留在 JSON 和测试附件中。

iPhone17Pro/iOS26.5 模拟器已运行实际拖拽与首页最大字号阿拉伯语横竖屏用例；系统运行时与用户的 26.5.2 实机不同，不能混作真机结论。其余最终专项、Duo 与后台状态见下方收尾记录及[最新上架进度](../release/上架进度-2026-10-24.md)。

保留初次 UI 失败：18.5 连续菜单操作后花园未选中；26.5 连续设置操作出现 window/控件 frame 为 inf、菜单未消失、开关未切换，断言没有删除或放宽。停止卡住的 Duo 安装/并发自动化，再串行复验。首次失败日志、附件与 xcresult 均保留，不将其写成通过。

过程构建 8 已正式归档并上传；最终构建 10 使用同一已验证的触感/球杆代码，Xcode27.1（27A9275）、iphoneos27.1，七语、隐私清单与签名检查通过。归档、测试、上传日志在 `work/phone-feedback-20261024/`。iOS 工程没有 Git 提交/推送，没有最终送审或公开发布。

串行复验：`Phone17SettingsFinal.xcresult` 的首页图标、滚动固定、English 入口、声音/触感独立切换恢复、花园积分入口用例通过（54.018秒）。没有删除花园或开关断言；补齐菜单消失、入口可点击、全屏页面呈现及花园选中的状态等待。`Phone17Final.xcresult` 保留其余实际拉杆和最大字号 RTL 横竖屏的通过结果及首次设置失败。

用户进一步纠正：隐私/语言须与品牌 label 同一行，不能单独占据一行而让左上角留白。构建 8 的独立图标行因此仅作过程记录；构建 9 将品牌移入同一固定顶栏，标题和模式卡片从顶栏下方开始。大字号允许品牌在自身区域换行，两个图标继续垂直居中、可点且不重叠。中英文同排、滚动固定及 RTL 最大字号横竖屏以 Header9 记录为准。

最终尺寸修订：用户要求图标缩小一半。构建 10 将可见底板由 48pt 缩为 24pt，符号由 22pt 缩为 11pt，背景描边与轻阴影随可见底板收小；透明点击区域仍为 48×48pt。顶栏品牌与工具同排、垂直居中，物理/触感逻辑沿用已验证的本轮实现。构建 8、9 已上传但不作为最终验收包；最终以 10 的后台核实结果为准。

最终验证：Header9Final 的品牌/图标同排、滚动固定、中英文入口以及最大字号 RTL 横竖屏均通过；图标减半后 Header10 的同排、隐私打开关闭、语言切换和固定顶栏专项再次通过（22.414秒）。原始附件名仍含 build9，是复用用例的采集标签；当前编译 Info.plist、正式归档与后台候选为构建 10。

[最终中文运行图](screenshots/phone-feedback-20261024/final10-home-chinese-clean.png)来自 iPhone17Pro/iOS26.5 模拟器原生 framebuffer。此前中文 XCTest 首帧采到系统 Apple 账户验证弹窗，保留为过程证据；最终图重新运行后采集，不重绘或删除图内内容，没有输入账户密码。

本轮 Duo 自动化与安装多次未进入测试，随后一次 iPhone17Pro 验证因目标进入 Shutdown 而失败；重启任务自己的设备/测试进程后串行手机专项通过。Duo 的本轮结果不能标为通过，旧构建 7 的姿势矩阵只是历史覆盖。没有改游戏代码来绕过运行时问题，也没有清除账户或模拟器数据。

最终对齐修订（构建 11）：两枚图标的热区改为 44pt、热区之间不再额外加 12pt，因此可见底板间距由 36pt 收至 20pt。可见底板仍为 24pt、符号 11pt。语言按钮的可见右边缘与模式卡片右边缘对齐，透明热区向右多伸出 10pt，保持在安全区内。品牌、按钮依然同排居中，卡片边界和游戏物理不变。构建 8—10 均是调整过程中上传的历史，不作为最终测试候选。
