# UI 生图提示词库（经过本次约束修订）

来源 P §9/15。下列为可复制的美术/构图草案，不是原文逐字复刻，也不是可执行指令或已生成素材。删除商店、PUTT 确认、旋球/摇杆、多参数面板、强制半折与固定像素布局；代码令牌见 specs/theming.md。

## 共用前缀

Friendly Physics 迷你高尔夫，柔和圆润球道、短绒草地、哑光珍珠白高尔夫球、清晰旗位与球洞。薄荷绿 #9BD4B8、深薄荷 #5FB98F、奶油白 #FBF7F0，少量日落橙 #F5A25D、树莓粉 #F0A7B9、蜜金 #E8B96A、清水蓝 #6FB4D6。低饱和、柔光、轻体积感；草地质感与入洞反馈是视觉重点。少量磨砂玻璃浮层、软圆角、高光细描边，不遮球路。留出真实 UIKit 文本/按钮区域，生成图不嵌入文字或可点击假按钮。

画幅使用 {目标容器比例} 与 {系统保留区遮罩}。概念板可以竖/横构图，但不指定某比例就是 DUO 真实屏幕；后续导出按实际 view bounds 与 displayScale。不要把附件 4:3、3:4、1398×2034、2007×2853 混用为工程尺寸。

## 共用后缀

无文字、无 logo、无水印、无真实品牌标识；无广告、价格、宝石续命、付费购买；不画多滑块、摇杆、独立击球按钮、旋球按钮；关键球位/洞位可读。重要操作留白完整避开提供的保留区，不能简单在画布中线留固定像素缝。生图负责视觉底图，真实文字/辅助功能标签由 UIKit 叠加。

## 页面与展示提示词（保留原库 12 项对应关系）

每段与共用前后缀组合使用。标“延后”的条目只是文档保留，不进入当前 MVP。

1. **regular 对局 / 原 01**：{目标容器比例}，大面积俯视微斜球道，柔软薄荷绿草坪、圆角白色沙坑、浅蓝运河、珍珠白球和清楚的红旗。仅一个拉杆代理的留白位置、一条方向预览和力度环；极少杆数信息留白。控制区域避开 {系统保留区遮罩}，背景可以连续延伸。无第二击球确认，无旋球。
2. **compact 开始页 / 原 02**：紧凑单栏构图，奶油白背景与圆形球道缩略画；为“开始一洞”“继续”和关卡/设置标准菜单留少量真实 UI 空位。主要操作靠近可触及安全区域，保留预览视野。无商店、排行榜和倒计时营销标签。
3. **控显分离 / 原 03**：两个用途明确的区域，一个完整展示球道，一个呈现小型地图与单一拉杆代理；轻玻璃材质，不预设左右各一半的硬件宽度。使用 {可用区域布局} 安排画面和控制；不画 PUTT、特殊球或独立方向摇杆。

5. **开球仪式 / 原 05**：薄荷绿草皮铺开，白色旗杆生长，球停在清楚的起点，暖金柔光和少量水纹。取消原文此处混入的入洞/金币面板；围绕开球本身构图。草皮 0.6s，旗杆 0.4s，提供可跳过的静态末帧。
6. **深夜场景 / 原 06，延后**：午夜 #101218 星空球场，蜜金星点与静态小地图，安静微光；单屏手动进入同样成立。无强制合盖、无计时压力；时钟具体功能未进入 MVP。
7. **成功结算 / 原 07**：小球进入洞口，蜜金短粒子庆祝与清晰结果卡留白，球道保持可辨。为星级/杆数/下一洞/重试留安全空间，按钮不在缝中央；粒子仅 0.8s，不画满屏暴雨，不依赖分享解锁。
8. **轻惩罚残局 / 原 08**：稳定球场与合法安全球位，少量警示红边和清楚的原因提示留白；继续与免费重试空间位于安全区域。去掉缩小浮岛、水位上涨、强风、换边/强制半折，保持同一个拉杆入口。红边反馈 0.3s。
9. **关卡选择 / 原 09**：compact 为清晰关卡列表与预览；regular 为章节 sidebar 与详情球道缩略图。先呈现青草地教学内容，预留星级位置，不写“60 HOLES/180 STARS”等未实现数量。无折叠专属内容锁。
10. **免费外观预览 / 原 10，延后**：奶油白展台上的球纹/旗布预览，简洁选中状态留白，材质变化不改变球速或属性。删除商店、价格、货币符号和购买入口。MVP 无此页面。
11. **本地传机计分 / 原 11，延后**：同一球道与紧凑玩家卡，当前回合状态用颜色加形状区分。每位玩家依次使用相同拉杆，取消一人方向一人力度与 PUTT 按钮。玩家数量/规则后续另定。
12. **App 图标 / 原 12，后续资产**：正方形奶油白到薄荷绿背景，中心珍珠白球与柔和金色短弧线，角落小旗，缩小仍清楚。无文字、无 logo。图标交付结构以目标 Xcode 资产规范核验，不把概念底图当完整图标资产。

**补充设置/暂停页（D，填补原库缺页）**：少量标准列表行与开关，声音、触感、控显分离、开球重播与返回游戏；真实文本由 UIKit 提供。视觉沿用奶油白/深草墨，布局服从系统容器，不做游戏化参数控制台。

## 六种动效提示词（P §15.4 经 U 覆盖）

1. **力度环**：同一拖动实时驱动弧长与方向，绿→金→橙→红有非颜色力度提示；不额外循环闪烁，不按持续时间蓄力。
2. **开球**：草皮铺开 0.6s，旗杆生长 0.4s；相机运动可弱化/跳过，不把球先自动击出；最终球停在起点等待拉杆。
3. **入洞**：蜜金粒子 0.8s 后收敛到静态结果；不以附件 1.2m 半径或长暴雨锁定物理与时序。
4. **滚动与碰撞**：珍珠白球、0.4s 装饰拖尾、小簇接触反馈；不借动画改变实际方向，不让碰撞粉尘遮住洞。
5. **面板/按钮**：面板入场候选 0.42s、按压 0.09s/0.94；真实热区不随缩放缩水；不用原文弹簧数值冒充 UIKit 原生参数。
6. **残局**：红边 0.3s + 稳定原因提示，场地不突然缩小，不恐慌倒数、不改变手势；用户仍能直接继续或重试。

以上六项均须提供 Reduce Motion 静态版本：无镜头摇晃/慢镜/粒子/草皮生长/抖动，保留可读状态和操作出口。动效时长来自令牌，不靠生成素材的帧率决定产品计时。
