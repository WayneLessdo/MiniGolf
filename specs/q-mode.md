# Q 版外观模式规格

状态：已按 2026-10-09 用户授权实现；2026-10-10 验证。原有输入、物理、奖励规格继续适用。

## 交互契约

1. 正常启动显示两个原生模式按钮；点击后进入同一游戏 session。
2. 模式是表现属性，不进入 `FPPhysicsWorld`、关卡 JSON、击球速度、标准杆、星级、额外球或惩罚公式。
3. 选择页暂停时钟与世界推进；关闭选择页继续原局。切换前取消未释放手势；已释放的一杆不重发事件。
4. 换关保留模式、心情和外观；场景恢复保存这三个字段。缺少新字段的 v1 快照默认为 classic/cozy/rice。
5. 常规操作仍只有单指拉杆 → 松手。没有第二次 PUTT、角度模拟滑块或传感器玩法。
6. 模式按钮使用可滚动原生 UI、Dynamic Type，按钮不跨越 reserved regions。中缝和内摄都使用现有系统区域 API 及坐标转换。

## 反馈时序（本轮设计值）

| 事件 | 反馈 | 时长 / 结束条件 |
| --- | --- | --- |
| aim | 球杆后撤、认真脸、强蓄力鼓脸汗滴 | 跟随同一 preview；cancel/release 立即结束 |
| shot | 原点挥杆跟随、手写击球词 | 0.24s / 1.35s；物理立即开始 |
| 入沙 | 沙沙短句 | 进入沙区时一次；再次进入至少间隔 1.2s |
| collision / canal-collision | 懵脸、叩/邦 | 表情 0.45s，文字 1.35s |
| near miss | 小球侧目、洞口眼睛、语气短句 | 每杆最多一次，文字 2.0s |
| hole capture | 咕噜 | 复用原有 sinking → success 状态机 |
| hole success | 粒子、观众欢呼、真实星级小卡 | 原有粒子 0.8s；小卡保留至继续 |
| out of bounds | 捡回来了/散步结束 | 沿用最后安全点，不增加处罚 |

擦洞判定是表现层草案：滚动中最近距离小于关卡 captureRadius × 1.8，随后远离至少 0.018 个世界单位。capture 会抑制同杆擦洞反馈；事件序号去重保证一次成功只庆祝一次。它不是进洞判断。

Reduce Motion：不运行装饰转动、跳动、挥杆跟随、粒子、镜头晃动或脉冲；可以显示当前静态姿态和文字。运行中的系统设置变化会移除已挂动画。原有草皮 0.6s、旗杆 0.4s、成功 0.8s、惩罚红边 0.3s 不改。

## 验收重点

- 同一输入在 classic/chibi 下逐步位置、速度、相位和奖励相同。
- 在滚动中打开选择页再更换模式，不丢失球位、速度、launch ID、杆数或耗时。
- 同一击球事件不重复挥杆/庆祝；入洞时不出现擦洞台词；新一杆可重新触发擦洞。
- 标准字号/最大辅助字号下可选择模式、操作拉杆和设置；继续使用原生按钮并按文字高度布局。
- 旧版快照与新版个性化快照可恢复，恢复本身不重播反馈。
- 所有截图标识环境和夹具来源，不把手绘概念、模拟器或测试初始球位当作真机实测。
