# 物理与轻量奖惩

本文件定义边界和事件合同，不实现完整物理，不把原文混杂数值写成既定常量。

## 物理边界（D）

- 单球、球场本地坐标、静态圆角墙/草地/沙坑/洞口/出界区域优先。输入为方向与归一化力度；世界坐标与屏幕投影分离。
- 力度到初速度映射、最大球速、摩擦、反弹系数、洞口吸附半径与速度、停球判定时间待 M2 调优。附件 12m/s、22m/s 镜头阈值、2.2m/1.2m 吸附口径互不协调，不能全部照搬。
- 轨迹是预览提示；能否做到附件所写平地误差 <2% 需先定义距离/采样测试，当前不承诺。MVP 优先短预测线与落点方向，不伪造完整精准球路。
- lastSafePosition 为最近一次通过合法站位校验的稳定球位（草地等可停球地面且不在洞/水/出界内），不是最后一帧位置。起点为兜底；首次出界也能恢复。
- reserved region 属于可视/可交互空间。系统中缝不是按像素动态插入的物理墙。关卡运河和碰撞由同一关卡数据定义；显示可围绕缝表现，折叠不改变碰撞图、风/坡、球速、得分。
- 同一世界状态开/合/转/折后连续；已松手的球不因布局重新求初速度。后台暂停时间不计入限时残局（D），回来不突然超时。

## 事件与奖励

| 事件 | 已确定行为 | 未定/草案 |
|---|---|---|
| legalShot | 松手只计一次杆；运动中不接第二杆 | 力度曲线待定 |
| holeCompleted | 标准杆内星级、入洞反馈 | 星级分档、超标准杆显示方式待定；不强制 3 杆=3星 |
| holeInOne | 金色重点反馈、可重试精修 | 回放在 M3 评估，不锁内容 |
| speedLineReward | 轻量奖励，不购买、不升级 | “加速线”存在语义歧义：拟议固定球道触线自动短暂加速；若实际指速度拖尾则仅表现。M2 前确认，当前不落数值 |
| extraBallReward | 自动记录额外球，永不构成付费/等待生命门槛 | 拟议一次可选的额外尝试；数量/作用域/使用与星级关系待确认 |
| outOfBounds | 轻反馈 → 回 lastSafePosition → 继续拉杆 | 不额外扣杆为 D 建议；本次击球已计的杆数保留 |
| timeout / obstacleLimitReached | 进入轻惩罚残局，输入不变 | 时间/碰障阈值、残局时长待调优；只统计有效接触事件，不能每帧叠计 |
| penaltyCompleted / penaltyExpired | 完成仍可结算，失败可免费重试/退出 | 不叠加递归惩罚、不扣生命、不清总进度（D） |

## 轻残局拟议流程

达到超时/有效多碰障阈值 → 红边 0.3s + 文本原因 → 保持合法球位（非法则回安全点）→ 用户可继续原拉杆完成当前洞，或暂停/重试。有限时版本也不得用频闪或强迫姿态施压；倒计时结束给明确出口，不弹消费弹窗。残局不加入移动缩岛、突然强风、反向控制或必需的视线盲区。

同一结果仅处理一次：按 shotID/holeAttemptID 防止重复计杆、重复星级、折叠后奖励重发。holeCompleted 为终态：一旦合法确认入洞，丢弃同帧重复失败事件；先出界的球不能同帧又算进洞。事件排序规则属于 D，须有边界测试。

## 后续验证（M2/M3）

- 原地松手/取消不计杆；一次有效释放一杆；碰撞回调抖动不累加惩罚。
- 出界从最近合法点恢复；起点兜底；免费重试无次数墙。
- 奖励一次结算；重载/切 scene 不重复；额外球耗尽仍可普通游玩。
- 相同击球状态与关卡在单屏/双屏/半折结果一致；铰链回调不进入物理或奖励依赖。
- 超时与入洞、碰障与出界同帧事件顺序稳定；暂停/恢复不吞一杆。
- 本轮仅规划，上述测试均未执行；没有生成物理代码或伪测试。
