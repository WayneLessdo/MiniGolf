# 地图选择、球场边界与一杆回放

2026-10-10。来源：本轮用户四项优化要求；现有 Swift + UIKit 工程为实现依据。早期“空骨架交付后停止”不适用于本轮明确授权的继续开发。

## 地图选择

- 普通/Q 两种模式均提供青草练习、运河回响、沙地余韵三张地图。地图数据复用现有已校验关卡，地形、障碍、球/洞位置和标准杆有差异。
- 地图按钮由“只看当前球道缩略图”改成原生选择菜单。菜单显示当前勾选项、地图特点及“选择后重新开始”。设置内提供相同子菜单。
- 选任一地图立即重建当局物理状态。即使选当前地图也重开；清空球速、杆数、星级、计时、碰撞、预测线、处罚、输入预览和回放。
- 保留模式、Q 版语气/球皮和声音/触感偏好。打开/关闭菜单本身不重开，选择动作才重开。

## 边界与拉杆状态

- 全屏视觉草地仍铺满视图。可玩世界按实际 view 的四边 safeAreaInsets 独立缩进，至少再留 `FPTheme.courseWallInset = 16pt`。保持等比投影，因此顶部实际距离也可能大于 16pt；不是固定地图拉伸或设备名判断。
- 16pt 是本轮建议的视觉间距令牌，不是硬件中缝宽度。reserved regions 继续使用系统数据。
- 正在拉杆时绘制世界外墙实线及球心可达边界虚线，边界外区域轻度压暗；墙线与物理世界使用同一坐标投影。
- `rolling / sinking / resetting / success` 不接受击球。滚动时拉杆 alpha 为 0.35，并显示锁图标与禁用辅助功能语义；收到真实 stopped 事件后才恢复 alpha 1 和输入。Reduce Transparency 下保持不透明，以锁标识说明禁用。

## 一杆进洞演出

- 第一杆真实捕获后：完成既有 sinking → 进入成功模型状态并计星一次 → 先显示居中的回放卡 → 回放结束显示 WIN 和继续入口。
- 回放记录世界坐标＋相对时间；常规约 30Hz，碰撞/停止/捕获额外记录关键采样。最多 512 点，溢出时减采样保留起点与后续终点；不重新运行物理。
- 播放倍率 0.5×，到洞后停留 0.8s；卡片周围播放非闪屏烟花。录制时间不影响原局得分、杆数或奖惩。
- 两杆及以上不触发一杆回放。回放中不能通过点击背景进入下一关；跳过只结束演出，仍需从 WIN 继续。
- Reduce Motion：展示完整静态轨迹 0.8s，取消球移动与烟花。运行中开启立即切静态；不重新启动动态演出。
- 回放中 HUD 暂隐，避免盖住卡片；窄屏上下、较宽的短容器左右排布。卡片和跳过按钮避开 division/occlusion；极小空间优先保留标题、球路、至少 48pt 跳过热区，次要说明移入辅助功能提示。
- 回放状态/轨迹随 scene 快照保存，切后台暂停；恢复不再发出结算/奖励事件。旧快照无回放字段时仍可恢复，直接沿用已有成功态。

## 验收

两种模式均验证三图选择、同图重开、真实弱击停球、真实一杆入洞、回放后换关。单测覆盖回放恢复/暂停/去重、运行中减少动态效果、两杆无回放、四边安全区和清局；大字号横屏和模拟保留区通过原生截图检查。工具与实际设备覆盖限制见 `docs/map-replay-delivery.md`。
