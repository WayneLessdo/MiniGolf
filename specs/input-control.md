# 单手势输入规格

状态：历史规划草案；后续实现见各期交付。2026-10-09 用户覆盖：WIN 后点击屏幕进入下一关，结算期间拖杆不产生瞄准、换关或击球；常规击球仍为单指拖拉松手。

## 输入合同

常规操作只有一个单指拖动。开始点是球附近的拉杆热区；控显分离时是控制区的球位代理。两者调用同一个输入模型。按住起点 p0，当前触点 p；拉回向量 v=p0−p，单位方向 v/|v| 与力度 clamp((|v|−deadZone)/(maxPull−deadZone),0,1) 同时更新。松手只提交一次方向+力度，不额外点击 PUTT。deadZone/maxPull 均待实测，maxPull 必须大于 deadZone。

这是拟议线性映射，不采纳附件互相冲突的“1mm≈0.8%/120px/±3px”。UIKit 触摸坐标统一 pt，物理使用独立球场坐标；按当前视口投影方向，缩放/迁移后不沿用旧屏幕坐标。不得用设备物理毫米或全局屏幕 scale 决定力度。

## 状态与异常

| 事件 | 转移/输出 | 验收 |
|---|---|---|
| 可击球时在合法拉杆区按下 | default → aiming，记录 p0 | 不增加杆数 |
| 拖过死区 | aiming → charging，实时方向/力度 | 无需长按蓄时 |
| 横向移动 | 更新方向，保持同一拉杆模型 | 不产生侧旋 |
| 回到死区 | charging → aiming | 松手视为取消 |
| 有效松手 | charging → rolling，产生唯一 shotID | 恰好一次击球/计杆 |
| 空间不足或预览跨出视口 | clamp 拉距、裁剪装饰预览 | 不能拉出无限力度 |
| recognizer cancelled/failed、scene 失活、切屏或容器几何改变 | 取消未释放拖动 → default | 不误发一杆；提示重新拉杆 |
| 第二手指/系统边缘手势 | 忽略额外触点或取消当前拖动 | 不随机改变方向 |
| rolling 期间触摸 | 不建立第二次击球 | 杆数不重复 |
| success 期间拖杆 | 保持当前 WIN | 不换关、不击球 |
| WIN 后点击屏幕或可访问的继续按钮 | success → 下一关 ready | 下一关 0 杆，同一点击最多换关一次 |
| 选项列表内拖动 / 点击列表外 | 列表滚动 / 关闭选项 | 不误选菜单、不误击球；关闭列表的点击不同时换关 |
| 停球/入洞/出界 | default/success/安全点恢复 | 由唯一规则事件决议 |

M1 使用状态夹具检验输入，M2 再连接运动模型。球运动中切屏保持同一模拟状态；几何只改变投影。后台冻结/恢复、已释放事件的幂等处理在 M2 做实测。

## 机制 → 单手势映射

难度为本项目实现与理解成本评估，不是原文定级。

| 原机制（来源） | 单手势映射或自动反馈 | 难度 | 简化替代/范围 |
|---|---|---|---|
| 拉力环（P §3） | 拉回方向+距离，松手击球 | 低 | M1 输入预览，M2 接运动 |
| 横滑旋球（P §3） | 与方向争用同一轴 | 高 | 删除旋球，横移只瞄准 |
| 半折摇杆+力度环+PUTT（P §4） | 无法保持一个连续手势 | 高 | 单个球位代理拉杆，去掉独立 PUTT |
| 展开开球（P §4 #01/#08） | 换关立即显示完整球场；开球演出保留手动重播 | 低 | 任意设备可按“重播开球”；角度只修饰演出 |
| 控显分离（P #02） | 控制区拖拉球位代理，画面同步 | 中 | 单屏可选控制托盘，空间不足收为球旁拉杆 |
| 半折掌机（P #03） | 原拉杆不变，由容器安排内容/控制区域 | 中 | 手动“控显分离”入口；不读角度切排版 |
| 角度风力/斜坡/跷跷板（P #04） | 不能与角度仅动效并存 | 高 | MVP 删除；后续固定坡/固定风关卡另评 |
| 中缝运河/碰撞（P #05） | 瞄准跨越/绕行；水纹自动 | 中 | 单屏显示同一关卡运河；硬件缝不生成新规则 |
| 角度开门（P #05） | 原方案依赖额外硬件输入 | 高 | 固定通路或后续固定周期门，MVP 不做 |
| 合盖结算/时钟（P #06） | 合盖不提交分数 | 中 | 明确继续/结算入口；时钟延后 |
| 双人一人方向一人力度（P #07） | 破坏统一输入 | 高 | 延后；未来传机轮流用同一拉杆 |
| 草地/沙坑/一次反弹（P §3/6） | 保持拉杆，结果由地形决定 | 中 | M2 只引入静态地形，一次一种 |
| 风车/移动平台/电梯/钟摆（P §3） | 等时机后同样松手 | 高 | 延后；首轮用静态圆角墙 |
| 传送门/磁吸/黑洞（P §3） | 接触自动触发 | 高 | 延后，无特殊球选择面板 |
| 星级/入洞反馈（U、P §5） | 规则自动结算 | 低 | 不增加领取/购买手势 |
| 加速线/额外球（U） | 拟议触线自动/奖励自动记账 | 中 | 语义与数值待定，不做道具滑块 |
| 出界（U） | 自动回最后安全点后继续拉杆 | 低 | 不看广告、不等生命 |
| 超时/多碰障残局（U） | 提示后保留同一拉杆 | 中 | 不缩岛/强风/反向控制；可重试退出 |
| 视线盲区/反向控制（P §5） | 破坏可预测输入/信息 | 高 | MVP 删除；以清晰遮挡提示与安全点替代 |

## 可访问性与手动等价

所有普通击球路径保持一种手势；无强制展开、摇摆、双指或按住另一个按钮。VoiceOver 等辅助技术的可访问动作属于后续专门评审项（如同一拉杆元素的方向/力度语义动作与提交），不宣称已经完成无拖拽操作验收，不在默认 HUD 显示多滑块。暂停、重开、重播、控显分离开关必须有可读名称与可达热区。

## 2026-10-09 后续选项修正

正式 UIKit 选项改为独立系统 UIMenu，不再向拉杆滚动面板追加列表。外部点击由菜单吸收并关闭；WIN 中关闭菜单的点击不同时进入下一关。全屏地图＋周边 HUD、拖杆期间隐藏/松手恢复当前为三套交互预览，待选定后实施，尚未改变正式击球输入或布局。
