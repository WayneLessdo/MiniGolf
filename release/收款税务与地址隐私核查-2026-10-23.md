## 2. 招商银行卡是否可以收款

结论：有作为候选收款账户的依据，但尚不能确认该具体账户一定可以入账，也没有证据说明它不支持。

- Apple银行目录此前已找到CNAPS `308581002329`，用户确认对应招商银行广州科技园支行。目录存在只证明可选路由，不验证这张卡的账户类型、状态或具体收入用途。
- 招商银行官方“境外汇款”说明：一卡通可接收境外汇款；境内个人收款姓名以开户证件姓名汉语拼音为准；接收须符合人民银行/外汇管理要求，部分业务以当地网点规定为准。该页面主要描述外币汇入，不能直接外推为这张卡的Apple人民币结算已获批准。
- Apple要求银行所在地区、路由号、币种及账户姓名/地址正确；银行账户属于注册开发者的同一实际个人或实体。Apple参考页另说明户名字符串不必与协议法律实体名称完全相同，这不免除真实身份与税务姓名正确性要求。
- 当前失败停在Apple的双重认证加载，银行列表仍为空；这是添加未成功，不能据此断言招商银行卡不兼容。
- Apple明确说明：必须提交付费合同所需的所有税表，Apple才处理银行信息。先完成姓名纠正及税表；银行资料可准备，但不把反复点击添加当作解决方案。

可直接向95555或开户支行询问：

> 我是个人App开发者，拟使用本人招商银行广州科技园支行的这张储蓄卡，接收Apple App Store软件销售收入，App Store Connect收款币种选CNY人民币。请核实该账户能否接收此类付款，是否有账户类别、限额或非柜面限制；若按跨境人民币汇入，是否支持，是否需提前登记、收入证明或收款申报？请同时确认收款拼音姓名格式和开户行CNAPS联行号。

实际付款通道以Apple及合作银行为准；不把CNY币种选择等同于一定使用某种跨境汇路。完整卡号只在招商银行官方安全渠道用于核实。

## 3. 能否先免费发布、以后收费

可以先推进同一个App免费发布，再完成付费条件并调整下载售价，不必为此新建App。Apple官方说明免费分发由开发者许可协议覆盖；本账户免费App协议当前有效，付费协议仍等待用户信息。

免费线：最终包验收 → 正式提交审核 → 审核通过后手动发布。银行尚未完成不是当前免费首发的收款前置；本轮没有正式送审或上线。

收费线：法律姓名更正及两份税表 → 银行资料处理、所需合规信息与有效付费协议 → 符合调价入口条件后保存价格日程。Apple官方明确预约价格变更需要接受付费协议并已提交App审核。

原目标仍为 **2026-11-23、美元基准0.99**，并非悄悄改成实际发布后一个月；四国最终使用各自当地价格。可以以后才补银行，但不能保证补资料当天就能收费：Apple说明姓名变更获批后同步至Connect还可能需要最多两周，银行也需处理。若届时条件未满足，则保持免费，待齐全后再设置未来生效日；目前没有已保存的涨价日程。

810号不应只归入“以后收费才做”。Apple说明其报送范围为自2025年7月起通过App Store分发App的中国开发者，本账户已提示缺少信息；没有在中国大陆发行并不自动免除。当前后台提示是避免付款中断，不据此宣称它已经阻止免费送审，也不宣称免费开发者可永久不填。

## 4. 地址会在哪里显示

| 数据用途 | 当前可见范围与限制 |
| --- | --- |
| Apple会员、商务协议、银行及税表中的住所 | 用于身份、合同、银行付款及税务处理，不因填写这些表就自动成为当前四国App产品页公开字段；Apple、获授权后台人员及必要的服务/监管处理方可能依法使用，不等于完全不向任何机构提供 |
| EU的DSA Trader联系地址、电话、邮箱 | 通过验证后会公开在EU App Store产品页。个人开发者可以提供实际可验证的业务地址或邮政信箱，不能编造；替代地址需要关联证明 |
| 当前四国范围 | 土耳其、阿联酋、巴西、墨西哥均非EU；按不在EU分发计划完成DSA，未提交私人地址或手机号用于DSA公开展示 |
| 当前公开支持页、隐私页 | 本轮读取英文线上正文，公开的是Wayne及支持邮箱，没有家庭地址、私人手机号、银行卡号或身份证号 |
| 销售方姓名 | 个人开发者的真实法律姓名会用于商店销售方展示；Apple说明法律实体更名后商店会展示新名称，不承诺匿名发布 |

810号官方列明向国家税务总局报送个人证件姓名/号码、商店标识、联系人及电话、开始经营日期，以及交易笔数、收入和退款金额；这是税务报送，不是公开商店字段。不要把“未公开家庭地址”误解成免税或不向税务机关报送。
